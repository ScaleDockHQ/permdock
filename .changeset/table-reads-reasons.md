`rls.tableReads` gives every `row` table a `reason`: the policy and file behind each `owner`, `condition` and `restrictive` entry, what `permdock supabase inspect` could not read for an `unknown` one, and for a `form` table the policy, tenant column or migration that keeps `permdock codemod bsb-access-tags` from moving it. `codemod bsb-access-tags --check` prints `would move N of M tables`.
