A membership row can hold roles in several columns: `role` in `rls.memberships` and `fromTable` `columns.role` accept an array of columns and `{ through, on, column }` references, and `fromJunction` accepts `roles: { sources }`. The row holds every non-null key in the token hook, `membershipsFor`, the database-mode helpers and the holder-count triggers.
