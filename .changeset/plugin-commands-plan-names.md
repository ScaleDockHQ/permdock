`permdock <name>` runs a `PermDockPlugin.commands` entry that has a `run` function when no built-in command has that name. The `constants` kind exports `planNames` and `PlanName`. Zod and Valibot row schemas end in `satisfies` against the `types.ts` row type, and an optional row field is typed `field?: T | undefined`; the generated validators import `./types.ts`, so generate `constants` with them.
