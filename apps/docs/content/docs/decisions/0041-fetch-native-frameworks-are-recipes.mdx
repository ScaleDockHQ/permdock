---
title: "0041: Fetch-native frameworks are recipes"
description: No new HTTP adapter entries for Fetch-native frameworks; Hono and Elysia stay thin wrappers over permdock/server. Extends 0023 to PermDock's own adapters.
---

## Status

Proposed, September 2026. Extends [0023](/docs/decisions/0023-compose-openapi-ecosystem) to first-party HTTP adapters. Does not remove existing entries.

## Context

[0023](/docs/decisions/0023-compose-openapi-ecosystem) forbids per-vendor packages for tools that already speak PermDock's wire formats. The same pressure exists inside the umbrella package: permix shipped one subpath per framework, and PermDock followed. Hono and Elysia already speak Fetch `Request`. Their `create.ts` files are thin wrappers that pass `c.req.raw` (or the native `Request`) to `permdock/server`. SvelteKit, Nitro and Remix would be the same file again.

HTTP adapters already return the same shape: `permdock`, `protect`, `permdockHandler`, `openapi`. Node bridges (Express, Fastify, Node, Nest) earn their extra code because they convert IncomingMessage. Next, agents, AuthZEN, MCP and terminal earn theirs because the runtime is not Fetch.

## Decision

1. **No new Fetch-native HTTP entries.** SvelteKit, Nitro, Remix, Astro server routes and similar consume `permdock/server` with a documented recipe, not `permdock/sveltekit`.
2. **Hono and Elysia stay.** They exist, they are thin, and removing them is churn without a design win. They remain the proof that a Fetch framework is a one-file wrapper.
3. **New server adapters** must either convert a non-Fetch request object or expose a runtime-specific hook (RSC `cache`, Nest module, tRPC middleware). If the input is already a `Request`, write a recipe.

This cycle does not delete adapters.

## Consequences

- The adapter matrix on [adapters](/docs/adapters) gains a "recipe" row for Fetch-native frameworks that are not Hono / Elysia.
- `tests/bundle` `ENTRIES` does not grow for those frameworks.
- The wire-permdock skill points at `permdock/server` for Fetch handlers.

## Alternatives considered

- **Delete Hono and Elysia now.** Rejected: they are already shipped in 0.1 and cost almost nothing; deletion is a separate breaking pass.
- **One adapter per framework forever.** Rejected: it is the permix packaging the 0.2 surface is walking away from.
