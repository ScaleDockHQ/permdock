---
title: "0044: Marketing site as a second Vercel Service"
description: The public landing site lives in apps/marketing at `/`. Docs stay on `/docs` with assetPrefix `/docs` instead of Next.js basePath, so MDX links stay `/docs/...`.
---

## Status

Accepted, September 2026.

## Context

`apps/docs` was the first Vercel Service and owned `/_next` plus a temporary `/` redirect to `/docs`. A marketing site at `/` needs a second Next.js service. Both emit `/_next/static`. Setting Next.js `basePath: '/docs'` on the docs app would prefix every `next/link` that already targets `/docs/...`, producing `/docs/docs/...`.

## Decision

1. **`apps/marketing` is the service at `/`.** Package name `marketing`. It owns `/`, `/_next`, `robots.txt`, `sitemap.xml` and the marketing routes (`/cloud`, `/pricing`, `/compare`, `/enterprise`, `/changelog`, `/blog`).
2. **Docs keep their URL namespace.** `/docs`, `/api/search`, `/mcp`, `/devtools`, `/llms.txt`, `/llms-full.txt`, `/llms.mdx` and `/og` stay on the docs service.
3. **Docs use `assetPrefix: '/docs'`, not `basePath`.** HTML requests `/docs/_next/...`. A service-scoped rewrite maps `/docs/_next/:path*` to `/_next/:path*` on the docs service. Catch-all `/_next/(.*)` goes to marketing.
4. **Local `pnpm marketing:dev` proxies docs paths** from the marketing origin (`:3000`) to the docs app (`:3001`) so one origin matches production.

## Consequences

- Marketing and docs deploy atomically as one Vercel project. Each service's `buildCommand` compiles `permdock` with `node --run build` before `next build`; `dist/` is not in git, and Vercel's bundled pnpm is not 12.3.1.
- A later Hono, Python or Vite service is a rewrite **above** the marketing catch-all.
- Preview deployments share one host; host-based splits are not used.

## Alternatives considered

- **`basePath: '/docs'` on docs.** Rejected: MDX already links to `/docs/...` and Fumadocs `loader({ baseUrl: '/docs' })` would double-prefix.
- **Separate Vercel projects.** Rejected: the marketing site and docs must ship together; Services give one preview URL.
- **Put marketing inside `apps/docs`.** Rejected: Fumadocs chrome and marketing chrome do not share a layout, and the docs `assetPrefix` decision only arises when two Next.js apps share a host.
