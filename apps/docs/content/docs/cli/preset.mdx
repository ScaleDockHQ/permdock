---
title: preset
description: Decode a preset code into its archetype, features, stack and services, or print the permdock.com/create link that opens it.
---

`permdock preset decode <code>` prints what a [preset](/docs/concepts/presets) code holds. `permdock preset url <code>` prints the [/create](https://permdock.com/create) link that opens it in the builder.

```bash
permdock preset decode p1AQIDBAc
permdock preset decode p1AQIDBAc --json
permdock preset url p1AQIDBAc
```

`decode` ends with the `permdock init` flags that select the same preset, leaving out defaults and the features the archetype and integrations turn on:

```txt
  archetype    b2b
  features     tenancy, custom-roles, operations, decision-log
  auth         custom
  backend      memory
  framework    next
  integrations mcp, shadcn
  services     none

  permdock init --archetype b2b --integration mcp --integration shadcn
```

With `--json`, `data` is the preset: `{ archetype, features, auth, backend, framework, integrations, services }`. `url` answers `{ url }`.

A code this version does not read, including one with a newer version prefix, exits `2`.

## Side effects

What each command may change; [side effects](/docs/cli#side-effects) explains each one.

| Command                  | Side effects |
| ------------------------ | ------------ |
| `permdock preset decode` | None         |
| `permdock preset url`    | None         |
