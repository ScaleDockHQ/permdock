---
title: generate
description: Write the files each configured plugin emits from the policy, in one command.
---

`permdock generate` loads the policy, builds one model, and runs every plugin in `plugins`. A config with `plugins: []` is valid and writes no plugin files. `--check` writes nothing and exits 1 when a file would change. The diff is on stdout, one `+` or `~` row per file. The receipt is on stderr.

## Usage

```bash
permdock generate
permdock generate --only rls --only powersync
permdock generate --check
permdock generate --dry-run
```

| Flag                | Meaning                                                                |
| ------------------- | ---------------------------------------------------------------------- |
| `--only <plugin>`   | Run this plugin. Repeat the flag to run more than one.                 |
| `--check`           | Exit 1 when a file on disk differs; write nothing. The diff is stdout. |
| `--dry-run`         | Report each change as `planned`; write nothing.                        |
| `--policy <module>` | The module exporting the policy. Default: `policy` in the config.      |

`--json` puts `files` and `summary` in the result. Each file has `path`, `plugin` and `outcome`. `outcome` is `created`, `updated`, `unchanged` or, with `--dry-run`, `planned`.

## Side effects

What each command may change; [side effects](/docs/cli#side-effects) explains each one.

| Command             | Side effects |
| ------------------- | ------------ |
| `permdock generate` | `files`      |

## Why

One command runs every plugin against the same model. Plugin order is the `plugins` array, then each plugin's `after` list.
