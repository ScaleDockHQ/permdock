# `@permdock/example-solid`

Minimal Solid wiring for `permdock/solid`: a server-built Snapshot v2, `PermDockProvider`, and one `<Protected>` guard. Vite is the intended bundler; this package typechecks the source without a Vite config.

```ts
import { PermDockProvider, Protected } from 'permdock/solid'
```
