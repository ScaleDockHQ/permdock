# `@permdock/example-svelte`

Minimal Svelte wiring for `permdock/svelte`: a server-built Snapshot v2, `setPermDock` in a layout, and `Protected` / `permission` stores. SvelteKit is the intended host; this package typechecks the public imports without a Vite config.

```ts
import { Protected, permission, setPermDock } from 'permdock/svelte'
```
