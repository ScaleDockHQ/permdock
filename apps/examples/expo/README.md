# `@permdock/example-expo`

Minimal Expo Router wiring for `permdock/react-native`: a persisted Snapshot v2, `PermDockProvider` with `storage`, and `usePermission` for `Stack.Protected`. This package typechecks the source without an Expo config.

```ts
import { PermDockProvider, usePermission } from 'permdock/react-native'
```
