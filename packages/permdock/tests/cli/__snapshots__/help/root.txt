permdock <version>: Collect, export, diff and check the permissions a PermDock policy declares

Usage  permdock <command> [flags]

Get started
  init        Write a preset's permissions, policy, app and wiring into the project
  preset      Decode a preset code, or print its permdock.com/create link
  skills      Install, update or list the PermDock Agent Skills
  doctor      Check a PermDock installation and print a fix for each finding
  completion  Print the shell completion script for bash, zsh or fish

Permissions
  collect  Scan the sources for definePermissions() and references; write the catalog and barrel
  catalog  Export the catalog as catalog JSON, JSON Schema or Markdown
  gen      Write typed constants, schemas and factories from the policy
  usage    Report unused, ungranted and role-less permissions and conditions on undeclared fields
  diff     Compare two policies or catalogs; exit 1 on a breaking change
  config   Check permdock.config.ts for unknown keys, or print the effective config

Database
  rls        Generate, import, verify or migrate Postgres RLS policies
  supabase   Generate the Supabase Custom Access Token Hook, or inspect its manifest
  powersync  Generate PowerSync Sync Streams from the policy, or verify them
  scim       Generate the Postgres tables postgresDirectoryStore keeps a SCIM directory in

Interop
  openapi  Emit security into an OpenAPI document, or import one into a definition
  arazzo   Check Arazzo workflows against the permissions
  scan     List authorization checks written without PermDock, to adopt it in an existing app
  casl     Import CASL rules into a generated module
  casbin   Import a Casbin model and policy into a generated module

Account and Cloud
  login   Log in to PermDock Cloud with the device flow (RFC 8628) or a loopback redirect (RFC 8252)
  logout  Revoke and delete the stored PermDock Cloud login
  whoami  Print the PermDock Cloud identity the CLI acts as
  cloud   Publish to or pull from a PermDock Cloud project

Upgrade
  codemod  Apply a release's renames to files that import permdock; list call sites to edit by hand

Global flags
  --cwd <dir>                        Run as if started in this directory
  --config <file>                    Config file (default permdock.config.{ts,mts,js,mjs})
  --json                             Print the cli-result-v1 JSON envelope on stdout
  --format <text|json|github|sarif>  Output format; github and sarif render findings
  -y, --yes                          Never prompt; take the answer the flags give
  --confirm <token>                  The token a consent_required result gave, once the person agreed
  --agent <auto|yes|no>              Agent mode: no prompts, JSON by default (default auto, PERMDOCK_AGENT)
  --debug                            Log each step and the cause of an error on stderr
  --color                            Styled output on a colour terminal
  --no-color                         Plain output
  -h, --help                         Print help
  -v, --version                      Print the permdock version

Run permdock <command> --help for its flags. Docs: https://permdock.com/docs/cli
