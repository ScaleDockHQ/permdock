permdock logout: Revoke and delete the stored PermDock Cloud login

Usage  permdock logout [flags]

Flags
  --url <url>  Issuer URL (default PERMDOCK_CLOUD_URL, then https://permdock.com/api)

Global flags
  --cwd --config --json --format --yes --agent --debug --color --help; see permdock --help

Examples
  permdock logout

Side effects  network, files
Docs  https://permdock.com/docs/cli/login
