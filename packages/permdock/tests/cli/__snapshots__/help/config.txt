permdock config: Check permdock.config.ts for unknown keys, or print the effective config

Usage  permdock config [flags]

Flags
  --print                    Print the effective config as JSON: the file, as written, and each default
  --fail-on <error|warning>  Lowest finding severity that exits 1 (default error)

Global flags
  --cwd --config --json --format --yes --agent --debug --color --help; see permdock --help

Examples
  permdock config
  permdock config --print

Side effects  none: reads only
Docs  https://permdock.com/docs/cli/config
