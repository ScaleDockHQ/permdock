permdock rls report: List each table's policies by command, role, origin and helper calls

Usage  permdock rls report [flags]

Flags
  --db-url-stdin  Read the Postgres connection string from stdin (default $DATABASE_URL, then $SUPABASE_DB_URL)
  --local         Connect to the local Supabase stack: DB_URL from supabase status in this project
  --stack <name>  With --local, the named stack of this worktree

Global flags
  --cwd --config --json --format --yes --effects-digest --agent --debug --color --help; see permdock --help

Examples
  permdock rls report
  permdock rls report --local --json

Side effects  database:read
Docs  https://permdock.com/docs/cli/rls
