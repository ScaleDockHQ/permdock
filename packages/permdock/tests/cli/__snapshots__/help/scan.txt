permdock scan: List authorization checks written without PermDock, to adopt it in an existing app

Usage  permdock scan [flags]

Flags
  --pattern <regex>  An extra regular expression to report (repeatable)
  --src <dir>        Directories to scan (default collect.srcPath or src) (repeatable)

Global flags
  --cwd --config --json --format --yes --agent --debug --color --help; see permdock --help

Examples
  permdock scan
  permdock scan --src app,lib --pattern isBeta

Side effects  none: reads only
Docs  https://permdock.com/docs/cli/scan
