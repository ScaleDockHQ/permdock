List authorization checks written without PermDock, to adopt it in an existing app (permdock scan)

USAGE permdock scan [OPTIONS] 

OPTIONS

        --cwd=<dir>    Run as if started in this directory                                  
    --config=<file>    Config file (default permdock.config.{ts,mts,js,mjs})                
             --json    Machine-readable output                                              
          -y, --yes    Never prompt; take the answer the flags give                         
            --color    Styled output on a colour terminal (Default: true)                   
         --no-color    Plain output                                                         
           --legacy    List authorization checks written without PermDock                   
  --pattern=<regex>    An extra regular expression to report, repeatable                    
       --src=<dirs>    Directories to scan, comma-separated (default collect.srcPath or src)
