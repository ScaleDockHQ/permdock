permdock openapi annotate: Write an operations map from @permission comments

Usage  permdock openapi annotate [flags]

Flags
  --routes <glob>  Glob of route modules with @permission comments
  --out <file>     File to write

Global flags
  --cwd --config --json --format --yes --confirm --agent --debug --color --help; see permdock --help

Examples
  permdock openapi annotate --routes 'app/**/route.ts'

Side effects  files
Docs  https://permdock.com/docs/cli/openapi
