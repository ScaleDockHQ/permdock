permdock openapi import: Turn an OpenAPI document into a generated definition

Usage  permdock openapi import [flags]

Flags
  --doc <path>                       OpenAPI document: a path, or a URL for import
  --out <file>                       File to write
  --validator <zod|valibot|arktype>  Schema library for the generated resources (default zod)
  --map <json>                       JSON mapping of operations to permissions
  --annotate                         Write x-permdock-permissions back into the document

Global flags
  --cwd --config --json --format --yes --confirm --agent --debug --color --help; see permdock --help

Examples
  permdock openapi import --doc openapi.yaml --out src/permissions.generated.ts

Side effects  files, network
Docs  https://permdock.com/docs/cli/openapi
