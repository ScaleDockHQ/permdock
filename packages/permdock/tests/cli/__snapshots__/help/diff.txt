permdock diff: Compare two policies or catalogs; exit 1 on a breaking change

Usage  permdock diff [before] [after] [flags]

Arguments
  before  A permissions.catalog.json or a module exporting policy (default the committed catalog)
  after   The same, for the new side (default the working tree)

Flags
  --impact           Run the fixtures through both sides and report changed outcomes
  --fixtures <file>  Fixtures file for --impact

Global flags
  --cwd --config --json --format --yes --confirm --agent --debug --color --help; see permdock --help

Examples
  permdock diff main.catalog.json permissions.catalog.json
  permdock diff ./old-policy.ts ./src/policy.ts --impact

Side effects  none: reads only
Docs  https://permdock.com/docs/cli/diff
