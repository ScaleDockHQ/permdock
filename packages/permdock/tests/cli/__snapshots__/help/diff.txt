Compare two policies or catalogs; exit 1 on a breaking change (permdock diff)

USAGE permdock diff [OPTIONS] [BEFORE] [AFTER]

ARGUMENTS

  BEFORE    A permissions.catalog.json or a module exporting policy
   AFTER    The same, for the new side                             

OPTIONS

        --cwd=<dir>    Run as if started in this directory                            
    --config=<file>    Config file (default permdock.config.{ts,mts,js,mjs})          
             --json    Machine-readable output                                        
          -y, --yes    Never prompt; take the answer the flags give                   
            --color    Styled output on a colour terminal (Default: true)             
         --no-color    Plain output                                                   
           --impact    Run the fixtures through both sides and report changed outcomes
  --fixtures=<file>    Fixtures file for --impact
