permdock usage: Report unused, ungranted and role-less permissions and conditions on undeclared fields

Usage  permdock usage [flags]

Flags
  --fail-on <error|warning>  Lowest finding severity that exits 1 (default error)
  --ignore <glob>            Permission keys or globs to skip (repeatable)
  --dynamic-as-used          Count computed permission references as uses

Global flags
  --cwd --config --json --format --yes --agent --debug --color --help; see permdock --help

Examples
  permdock usage
  permdock usage --fail-on warning

Side effects  none: reads only
Docs  https://permdock.com/docs/cli/usage
