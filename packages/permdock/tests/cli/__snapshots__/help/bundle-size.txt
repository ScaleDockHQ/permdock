permdock bundle size: Report bundle bytes per role and shared part, raw and gzip

Usage  permdock bundle size [flags]

Flags
  --policy <module>  Module exporting the policy (default policy in the config)
  --budget <bytes>   Bytes the bundle may weigh (default budgets.bundle)

Global flags
  --cwd --config --json --format --yes --effects-digest --agent --debug --color --help; see permdock --help

Examples
  permdock bundle size
  permdock bundle size --budget 32768 --json

Side effects  none: reads only
Docs  https://permdock.com/docs/cli/bundle
