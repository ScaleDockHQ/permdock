permdock catalog: Export the catalog as catalog JSON, JSON Schema or Markdown

Usage  permdock catalog [flags]

Flags
  --kind <catalog|json-schema|markdown>  What to print: the catalog, its JSON Schema, or a Markdown table (default catalog)
  --permissions <module>                 Module exporting the permissions (default permissions in the config)
  --include <key>                        Permission keys or prefixes to keep (repeatable)

Global flags
  --cwd --config --json --format --yes --agent --debug --color --help; see permdock --help

Examples
  permdock catalog --out permissions.catalog.json
  permdock catalog --kind markdown

Side effects  files
Docs  https://permdock.com/docs/cli/catalog
