Export the catalog as JSON, JSON Schema or Markdown (permdock catalog)

USAGE permdock catalog [OPTIONS] 

OPTIONS

                      --cwd=<dir>    Run as if started in this directory                    
                  --config=<file>    Config file (default permdock.config.{ts,mts,js,mjs})  
                           --json    Machine-readable output                                
                        -y, --yes    Never prompt; take the answer the flags give           
                          --color    Styled output on a colour terminal (Default: true)     
                       --no-color    Plain output                                           
  --format=<json|schema|markdown>    Output format (Default: json)                          
                  --from=<module>    Module exporting the permissions, instead of the config
                  --include=<key>    Permission keys or prefixes to keep, repeatable
