permdock init: Write a preset's permissions, policy, app and wiring into the project

Usage  permdock init [flags]

Flags
  --preset <code>       A preset code from permdock.com/create
  --archetype <name>    Without --preset: b2b, agent, marketplace, api, internal or consumer
  --framework <name>    Without --preset: next, hono, express or none
  --feature <name>      Without --preset: a feature to add (repeatable)
  --integration <name>  Without --preset: ai-sdk, mcp, shadcn or react-native (repeatable)
  --out-dir <dir>       Source directory the files go in (default src)
  --dry-run             Print what would change; write nothing
  --force               Overwrite files PermDock did not write or that changed by hand

Global flags
  --cwd --config --json --format --yes --confirm --agent --debug --color --help; see permdock --help

Examples
  permdock init --preset p1AQIDBAc
  permdock init --archetype b2b --framework hono --integration mcp

Side effects  files
Docs  https://permdock.com/docs/cli/init
