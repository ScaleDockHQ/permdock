Write a preset's permissions, policy, app and wiring into the project (permdock init)

USAGE permdock init [OPTIONS] 

OPTIONS

         --cwd=<dir>    Run as if started in this directory                                 
     --config=<file>    Config file (default permdock.config.{ts,mts,js,mjs})               
              --json    Machine-readable output                                             
           -y, --yes    Never prompt; take the answer the flags give                        
             --color    Styled output on a colour terminal (Default: true)                  
          --no-color    Plain output                                                        
     --preset=<code>    A preset code from permdock.com/create                              
  --archetype=<name>    Without --preset: b2b, agent, marketplace, api, internal or consumer
  --framework=<name>    Without --preset: next, hono, express or none                       
    --feature=<name>    Without --preset: a feature to add, repeatable                      
      --agent=<name>    Without --preset: ai-sdk or mcp, repeatable                         
         --ui=<name>    Without --preset: shadcn or react-native, repeatable                
         --src=<dir>    Source directory the files go in (default src)                      
           --dry-run    Print what would be written; write nothing                          
             --force    Overwrite files that already exist
