Log in to PermDock Cloud with the device flow (RFC 8628) or a loopback redirect (RFC 8252) (permdock login)

USAGE permdock login [OPTIONS] 

OPTIONS

      --cwd=<dir>    Run as if started in this directory                                   
  --config=<file>    Config file (default permdock.config.{ts,mts,js,mjs})                 
           --json    Machine-readable output                                               
        -y, --yes    Never prompt; take the answer the flags give                          
          --color    Styled output on a colour terminal (Default: true)                    
       --no-color    Plain output                                                          
      --url=<url>    Issuer URL (default PERMDOCK_CLOUD_URL, then https://permdock.com/api)
       --loopback    Use a 127.0.0.1 redirect with PKCE instead of the device flow         
          --write    Also request catalog:write, for permdock cloud push                   
           --open    Open the browser at the verification URL (Default: true)              
        --no-open    Print the URL only
