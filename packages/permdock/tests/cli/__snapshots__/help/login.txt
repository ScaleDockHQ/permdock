permdock login: Log in to PermDock Cloud with the device flow (RFC 8628) or a loopback redirect (RFC 8252)

Usage  permdock login [flags]

Flags
  --url <url>              Issuer URL (default PERMDOCK_CLOUD_URL, then https://permdock.com/api)
  --loopback               Use a 127.0.0.1 redirect with PKCE instead of the device flow
  --scope <catalog:write>  Scopes beyond projects:read and policy:read; catalog:write for permdock cloud push (repeatable)
  --open                   Open the browser at the verification URL
  --no-open                Print the URL only

Global flags
  --cwd --config --json --format --yes --agent --debug --color --help; see permdock --help

Examples
  permdock login
  permdock login --scope catalog:write

Side effects  network, files
Docs  https://permdock.com/docs/cli/login
