permdock cloud push: Publish the catalog, policy and manifest to a Cloud project

Usage  permdock cloud push [flags]

Flags
  --url <url>        Cloud API base URL
  --manifest <file>  Manifest file to send or write (default permdock.manifest.json)
  --project <id>     Cloud project id (default PERMDOCK_CLOUD_ENV, then VERCEL_ENV, then production)
  --dry-run          Print what would change; write nothing
  --key-stdin        Read PERMDOCK_CLOUD_KEY from stdin

Global flags
  --cwd --config --json --format --yes --confirm --agent --debug --color --help; see permdock --help

Examples
  permdock cloud push --dry-run
  permdock cloud push --project prj_123

Side effects  network, cloud:write
Docs  https://permdock.com/docs/cli/cloud
