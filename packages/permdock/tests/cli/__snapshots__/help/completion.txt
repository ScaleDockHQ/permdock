permdock completion: Print the shell completion script for bash, zsh or fish

Usage  permdock completion <shell> [flags]

Arguments
  shell  bash, zsh or fish

Global flags
  --cwd --config --json --format --yes --agent --debug --color --help; see permdock --help

Examples
  permdock completion zsh > ~/.zfunc/_permdock
  eval "$(permdock completion bash)"

Side effects  none: reads only
Docs  https://permdock.com/docs/cli/completion
