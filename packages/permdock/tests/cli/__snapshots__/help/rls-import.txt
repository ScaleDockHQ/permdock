permdock rls import: Turn existing RLS policies into a generated definition

Usage  permdock rls import [flags]

Flags
  --sql <path>                       SQL file or folder to read
  --db-url-stdin                     Read the Postgres connection string from stdin (default $DATABASE_URL, then $SUPABASE_DB_URL)
  --out <file>                       File to write
  --validator <zod|valibot|arktype>  Schema library for the generated resources (default zod)
  --memberships <table>              Membership table as <table>:tenant,user,role

Global flags
  --cwd --config --json --format --yes --confirm --agent --debug --color --help; see permdock --help

Examples
  permdock rls import --sql schema.sql --out src/permissions.generated.ts
  permdock rls import --db-url-stdin --out src/permissions.generated.ts

Side effects  files, database:read
Docs  https://permdock.com/docs/cli/rls
