Scan the sources for definePermissions() and permission references; write the catalog and barrel (permdock collect)

USAGE permdock collect [OPTIONS] 

OPTIONS

      --cwd=<dir>    Run as if started in this directory                    
  --config=<file>    Config file (default permdock.config.{ts,mts,js,mjs})  
           --json    Machine-readable output                                
        -y, --yes    Never prompt; take the answer the flags give           
          --color    Styled output on a colour terminal (Default: true)     
       --no-color    Plain output                                           
          --check    Exit 1 when the catalog on disk is stale; write nothing
     --src=<path>    Source roots or globs, repeatable or comma-separated   
     --out=<file>    Catalog file to write
