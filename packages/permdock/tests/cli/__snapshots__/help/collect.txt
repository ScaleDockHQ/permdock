permdock collect: Scan the sources for definePermissions() and references; write the catalog and barrel

Usage  permdock collect [flags]

Flags
  --check       Exit 1 when a file on disk is stale; write nothing
  --src <path>  Source roots or globs (repeatable)
  --out <file>  Catalog file to write
  --watch       Collect again when a source, config or policy file changes

Global flags
  --cwd --config --json --format --yes --agent --debug --color --help; see permdock --help

Examples
  permdock collect
  permdock collect --check
  permdock collect --watch

Side effects  files
Docs  https://permdock.com/docs/cli/collect
