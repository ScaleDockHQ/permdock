permdock codemod: Apply a release's renames to files that import permdock; list call sites to edit by hand

Usage  permdock codemod <version> [paths...] [flags]

Arguments
  version  The release to migrate to (0.5)
  paths    Files or directories to rewrite (default the working directory)

Flags
  --dry-run  Print what would change; write nothing

Global flags
  --cwd --config --json --format --yes --agent --debug --color --help; see permdock --help

Examples
  permdock codemod 0.5 --dry-run
  permdock codemod 0.5 src

Side effects  rewrite
Docs  https://permdock.com/docs/cli/codemod
