Apply a release's renames to files that import permdock; list call sites to edit by hand (permdock codemod)

USAGE permdock codemod [OPTIONS] [VERSION] [PATHS]

ARGUMENTS

  VERSION    The release to migrate to (0.5)                                 
    PATHS    Files or directories to rewrite (default: the working directory)

OPTIONS

      --cwd=<dir>    Run as if started in this directory                  
  --config=<file>    Config file (default permdock.config.{ts,mts,js,mjs})
           --json    Machine-readable output                              
        -y, --yes    Never prompt; take the answer the flags give         
          --color    Styled output on a colour terminal (Default: true)   
       --no-color    Plain output                                         
        --dry-run    Report the renames without writing any file
