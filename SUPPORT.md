# Support

- **Bugs** — open a [bug report](https://github.com/ScaleDockHQ/PermDock/issues/new?template=bug.yml).
- **Public API changes** — open an [RFC](https://github.com/ScaleDockHQ/PermDock/issues/new?template=rfc.yml) before a pull request.
- **Adapters** — use the [adapter issue](https://github.com/ScaleDockHQ/PermDock/issues/new?template=adapter.yml) if you are proposing or contributing an adapter.
- **Docs** — [docs issue](https://github.com/ScaleDockHQ/PermDock/issues/new?template=docs.yml) or a pull request against `apps/docs/content/docs`.
- **Questions** — GitHub Discussions, once enabled. Until then, a docs issue is fine.
- **Security** — [`SECURITY.md`](./SECURITY.md) only. Never a public issue.

The product plan is [`PRODUCT.md`](./PRODUCT.md). Maintainer conventions are [`AGENTS.md`](./AGENTS.md). Docs live under [`apps/docs/content/docs`](./apps/docs/content/docs).
